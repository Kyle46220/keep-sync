KeepSync brings selected Google Keep notes into your Markdown workflow, connecting Google Drive, GitHub, and Obsidian.

One personal workflow
01 / CAPTURE

Write in Keep.

Capture an idea, a checklist, or a note. Select what belongs in your Markdown workflow.

02 / CONNECT

Let it sync.

Scheduled background tasks export selected notes and synchronize the configured Drive folder.

03 / CONTINUE

Keep working.

Use your Markdown files through GitHub or your Obsidian setup, with links back to their source.

Export selected notes

Notes containing #export are exported as Markdown to a designated Google Drive folder and the configured GitHub repository. Successfully exported notes receive an exported label.

Two-way note sync

Notes selected with the obsidian label or #obsidian text synchronize with Markdown files in a separate Drive folder. Your Obsidian setup must make those files available in your vault; KeepSync does not connect directly to the Obsidian app.

Your accounts, your files

KeepSync runs on Google Cloud and accesses connected accounts using configured credentials. Drive access is used to read and write files in the designated folders. Read the privacy policy for the data processed and how to revoke access.
